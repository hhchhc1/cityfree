## 二、按区域找文件

文件名格式 `tile_<X起点>_<Z起点>.glb`，例如：

- `tile_1500_0.glb` → X 1500~2000、Z 0~500
- `tile_2000_-500.glb` → **X 2000~2500、Z −500~0（州署/衙门就在这块）**

## 三、导入步骤（造世界编辑器）

1. 打开编辑器 → 资产/模型 → 导入
2. 选一个 `tile_xx_yy.glb`
3. 拖进场景，按文件名里的 X/Z 起点摆位（每块间隔 500 米）
4. 重复导入其余块

## 四、碰撞怎么加

GLB 里**只有几何体，没有碰撞**。碰撞数据在 `colliders.json`，格式：

```json
{ "x0": 1980.5, "z0": -320.2, "x1": 2070.1, "z1": -260.4, "y0": 0.0, "y1": 12.5 }
```

含义：一个长方体碰撞盒，X 从 x0 到 x1、Z 从 z0 到 z1、Y 从 y0 到 y1（米）。

在编辑器里对应做法：
- 若编辑器支持**导入碰撞数据/碰撞盒** → 直接按上表批量建。
- 若只支持**可视化碰撞盒** → 用 JSON 里的数值手动拉盒（3244 个太多，建议优先做「主干道两侧 + 州署 + 你实际会走到的区域」）。
- 若编辑器支持**按模型自动生成碰撞** → 直接给导入的建筑勾上，比手摆快。
