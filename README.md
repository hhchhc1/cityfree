# 城市自由人（City Free Man）

3D 第三人称城市漫游游戏：逛街、开车、打击罪恶、躲城管追捕、商城买武器。
纯前端单文件实现，**无构建步骤**，用 [three.js r128](three.min.js) 渲染。

线上测试地址：**https://hhchhc1.github.io/cityfree/**

---

## 一、文件说明

## 二、本地运行

方式一（推荐）：用任意本地静态服务器打开项目目录，然后访问 `index.html`。
方式二：直接双击 `城市自由人.html`。
但 `file://` 下浏览器会拦截部分资源（音乐等），这是浏览器的安全限制，不是游戏 bug。

## 三、发布上线流程 ⚠️ 每次改完代码都要走一遍

该网址由 **GitHub Pages 从 `master` 分支根目录自动构建**，入口是 `index.html`。
只要推送到 `master`，网站就会自动更新（通常 30~60 秒后生效）。

```bash
# 1. 改完代码后，先把主文件同步到发布副本（这一步最容易忘！）
copy "城市自由人.html" "index.html"

# 2. 更新版本号（强烈建议，见下节）

# 3. 提交
git add "城市自由人.html" "index.html"
git commit -m "fixNN: 本次改了什么"

# 4. 推送（推送后线上才会更新）
git push origin master
```

**5. 等 30~60 秒后验证**：打开线上地址，看右上角版本号是否为刚写的值。
若没变，多半是浏览器缓存 —— 强制刷新（`Ctrl+F5`）或用无痕窗口再看。

### 常见问题排查

| 现象 | 原因 |
|---|---|
| 线上完全没变化 | 90% 是漏了第 1 步（没同步 `index.html`），或漏了第 4 步（没 push） |
| 版本号对但画面是旧的 | 浏览器缓存，强制刷新或无痕窗口 |
| 手机上没音乐 | 手机浏览器要求"用户先点一下"才允许播放，点一下屏幕即可 |
| 页面顶部出现红色错误条 | 游戏内置的运行时错误可视化，把那条截图发出来即可定位 |

## 四、版本号约定

游戏主文件里有一个构建版本常量，右上角 HUD 会显示它：

```js
const BUILD = '20261022-fix41-airport';
```

**每次改动都要把末尾数字 +1**，它是确认"浏览器加载的是新文件而不是缓存"的唯一依据。

> 历史教训：该常量曾从 `fix16` 之后长期未更新（`fix17`~`fix39` 都停在 `fix16`），
> 导致无法用它判断线上新旧，排查问题时非常误导。请务必每次同步。

## 五、备份约定

改动前先复制一份主文件，命名为 `城市自由人.html.bak-fixNN`，例如：

```
城市自由人.html.bak-fix48-before-linhai
```

这类文件已被 `.gitignore` 忽略，不会误提交进仓库。

## 六、代码维护提示（重要，能省很多时间）

单文件 2.3 万行，历史注释非常详细（每条修复都写了"原来错在哪、怎么修的"），
改动前建议先读附近注释。以下几条是踩过坑的硬性约定：

1. **顶层 `const` 会踩 TDZ**：主脚本在文件末尾才被"间接 eval"执行，但有些函数在**更早**
   （如 `addWeaponMesh` 在 `polishWeaponModel` 之前）就会被调用。凡是可能被提前读取的
   模块级状态，必须写成 `function`，或用自保留写法：
   ```js
   var X = (typeof X === 'undefined') ? 默认值 : X;
   ```
   写成 `const` 会抛 `ReferenceError`，**整个游戏脚本中断 → 白屏**。

2. **共享材质必须打 `userData.lodShared = true`**：尸体淡出（`fadeFigure`）会直接改材质
   透明度，共享材质不标记就会"一个人淡出、全城一起变透明"。

3. **`scale` 赋值前必须 `isFinite` 兜底**：NaN 会顺父链传染，导致包围球 NaN，
   视锥剔除永久失效（three.js 会一直刷 "Computed radius is NaN"）。

4. **会动/会变色的物体要登记**：`dynamicExtras.push(...)` 或 `registerDynamicObject(...)`，
   否则会被 `batchStaticScene()` 当成静态物体合并掉，表现为"东西少了/动画失效"。

5. **性能主线是"消灭 draw call"**：几何体共享 → 按材质合并 → 顶点色合并 → 静态合批 → 距离剔除。
   改动模型时请沿用共享几何体与共享材质，不要每个物体 `new` 一份。

6. **新建筑必须排在 `buildOuterRoadMeshes()` 之前**登记进 `buildings`，
   否则外围环道不会避让它（隐式的构建顺序契约）。

## 七、技术栈

- three.js **r128**（注意：`InstancedMesh` 在此版本无包围球，必须 `frustumCulled = false`）
- 无打包、无构建：单个 HTML + 一个引擎 js
- 存档：`localStorage`，key `cityFreeMan.save.v1`
- 音效：Web Audio 实时合成（无音频文件依赖，音乐除外）
- 适配：手机触屏（浮动摇杆 + 可自定义 HUD 按钮布局）与桌面键鼠
